# NEWTON PROJECT

A Python coursework repository with weekly examples and implementations centered on numerical methods, including Newton–Raphson root finding and GUI demos.

## Setup

1. Install Python 3.8 or newer.
2. Open a terminal in the repository root.
3. Install the GUI dependency if you plan to run the interface examples:

```bash
pip install customtkinter
```

## Usage

From the repository root, run any `.py` file directly. For example:

```bash
python "WEEK 2 source code.py"
```

Or run a week-specific file inside a documents folder, such as:

```bash
python "WEEK 10 DOCUMENTS\WEEK-10-source-code.py"
```

### Common file categories

- `WEEK X source code.py` — Weekly lesson examples.
- `WEEK X DOCUMENTS/` — Supplemental project files and documentation.
- `week12_source_code.py` — Example for week 12.

## Features

- Newton–Raphson root finding examples
- GUI applications built with `tkinter` and `customtkinter`
- Weekly structured learning examples
- Multiple root-finding function demonstrations

## Limitations

- Not all files are fully integrated; many are standalone week assignments.
- The repository is primarily educational and may contain placeholder or partial implementations.
- Some examples depend on `customtkinter`, so those require additional installation.
- There is no centralized package or installer; run scripts individually.

## Notes

- Use Python 3.8+ for best compatibility.
- If you encounter a missing module error, install the required dependency with `pip`.
